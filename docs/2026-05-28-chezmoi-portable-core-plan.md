# Chezmoi Portable Core Integration Plan

## Goal

Make the dotfiles repo safe enough to apply the portable shell/tmux/git core on
`pongo`, while avoiding desktop app config, SSH key assumptions, auth files, and
tool state.

## Scope

- Clean `dot_bashrc` so optional workstation tools only affect `PATH` when they
  are installed on the current machine.
- Merge the VPS tmux preference `setw -g mode-keys vi` into `dot_tmux.conf`
  and guard TPM startup when TPM is not installed.
- Merge GitHub CLI credential helper settings into `dot_gitconfig` without
  hard-coding `/usr/bin/gh`.
- Apply only `.bashrc`, `.bash_profile`, `.tmux.conf`, and `.gitconfig` on
  `pongo` for this pass.

## Exclusions

- Do not manage `~/.config/plaud-dl/config.json`; it contains auth material.
- Do not manage `~/.config/gh/hosts.yml`; it is generated by `gh auth login`.
- Do not manage Claude/Codex auth, history, plugin caches, or local permission
  state in this pass.
- Do not apply repo desktop app config or repo `~/.ssh/config` to `pongo` in
  this pass.

## Validation

- Run shell syntax checks on `dot_bashrc`, `dot_bash_profile`, and
  `dot_tmux.conf` where applicable.
- Run `git config --file dot_gitconfig --list`.
- Run `chezmoi diff --source <repo> ~/.bashrc ~/.bash_profile ~/.tmux.conf ~/.gitconfig`.
- Apply only those four targets if the diff is limited to the intended changes.
